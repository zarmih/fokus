# План Фазы 2: Персональная программа и Калибровка (Fokus)

## 1. Концепция
Phase 2 внедряет персональную программу тренировок на основе начальной калибровки уровня, предлагая пользователю ежедневный ритуал на ~15 минут. Это отходит от случайных сессий и дает четкую цель и путь развития (без копирования существующих решений типа Wikium - полностью свой, премиальный дизайн).

## 2. Ключевые фичи (Скелет)
- **Калибровка**: Короткая серия тестов для определения начального уровня (Fokus Index) в каждой из 5 категорий (Память, Внимание, Логика, Скорость, Гибкость).
- **Персональная программа**: Подборка из каталога упражнений на каждый день, направленная на развитие отстающих навыков.
- **Трекинг прогресса**: Сохранение этапов программы, ежедневное расписание.

## 3. Техническая реализация
- **Типы**: Добавление состояний калибровки и плана программы в `UserProfile` (хранится в localStorage).
- **Экран Программы/Калибровки**: Выделенный UI для запуска тестов и просмотра текущего плана.
- **Совместимость**: Существующие упражнения работают без изменений.
