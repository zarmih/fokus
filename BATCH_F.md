# Batch F Exercises

1. `vigil-probe`: Игрок должен быстро нажимать только на целевой объект, игнорируя дистракторы. Развивает устойчивость внимания.
2. `stack-span`: Запоминание и обновление стека элементов с проверкой состояния на разной глубине. Тренирует рабочую память.
3. `rule-induce`: Игрок выявляет скрытое правило классификации карточек по их признакам. Развивает логику и распознавание паттернов.
