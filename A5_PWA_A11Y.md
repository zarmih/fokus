# A5 PWA and Accessibility (a11y) Pass

В рамках задачи A5 были проведены работы по улучшению PWA-инфраструктуры и доступности (a11y) приложения Fokus.

## PWA (Progressive Web App)

1. **Офлайн и кэширование (`generate-sw.ts`)**:
   - Обновлена стратегия кэширования для навигационных запросов (navigate). Теперь используется подход Network-First с возвратом к закэшированному `index.html` при отсутствии сети. Это предотвращает создание излишних копий `index.html` в кэше для каждого маршрута и гарантирует, что пользователь всегда получит свежую версию приложения при наличии сети, а в офлайне не столкнётся с ошибками маршрутизации.
2. **Установка (Install Prompt)**:
   - В `pwa-install.ts` добавлен механизм подписки (`onInstallPrompt`) на событие `beforeinstallprompt`. Ранее событие могло быть перехвачено до рендера экрана настроек, из-за чего кнопка установки не отображалась.
   - В `settings.ts` теперь корректно отображается кнопка установки с проверкой поддержки браузера и текущего режима отображения (display-mode).

## Доступность (Accessibility / a11y)

1. **Ориентиры (Landmarks)**:
   - Приложение уже содержит корректные landmark-теги (`<header>`, `<nav>`, `<main>`) в основной оболочке (`shell.ts`).
   - В `index.html` для стартового (boot) экрана добавлен `<main role="main">`, что позволяет скринридерам сразу ориентироваться на загрузочном экране.
2. **Фокус (Focus)**:
   - Навигация по фокусу (псевдокласс `:focus-visible`) уже глобально прописана в `styles.css`.
   - Основной контейнер получает фокус программно (`focusMain()`) при смене экранов для корректного чтения контента (SPA-паттерн).
3. **Уменьшение движения (Reduced Motion)**:
   - Обработка `prefers-reduced-motion` уже покрыта в стилях (`styles.css` и в JS логике анимаций). Отключаются пульсации, сдвиги и масштабирование, если пользователь предпочитает минимум анимаций.
4. **Контрастность (Contrast)**:
   - Тема поддерживает режим `prefers-contrast: more`, где усиливаются границы и убираются некоторые свечения (glow) для лучшей читаемости.
5. **Aria-атрибуты**:
   - `aria-live="polite"` используется для скринридер-анонсов.
   - Скринридер-only блоки (class `sr-only`) настроены корректно.
   - Интерактивные элементы, включая радар-график Фокус Индекса (`charts.ts`) и карточки недели, снабжены исчерпывающими текстовыми описаниями (`aria-label`, `role="img"`).
   - Радиогруппы (настройки цели, длительности) используют корректные роли `radiogroup`, `radio` и `aria-checked`.

Все изменения атомарны, не затрагивают бизнес-логику тренажёров (`registry.ts`, `today`, `coach`) и сохраняют стабильность тестов и сборки.
