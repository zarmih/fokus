# Стратегический план развития Fokus

Основываясь на анализе рынка когнитивных тренажеров (Lumosity, Peak, Elevate) и современных исследований в области нейропсихологии, я составил комплексный план развития приложения Fokus. План разбит на 4 ключевых направления.

## 1. Научная база и новые механики (Neuroscience)
Существующая архитектура `engine/view` идеально подходит для внедрения научно обоснованных тестов.
- [x] **Dual N-Back (Двойной шаг назад)**: Добавление звукового канала к уже реализованному визуальному N-Back. Это единственный тренажер, для которого научно доказан эффект переноса (far transfer) на подвижный интеллект (fluid intelligence).
- [x] **Corsi Block-Tapping (Тест Корси)**: Тест на пространственную рабочую память. Пользователь должен повторить последовательность загорающихся кубиков на экране.
- [x] **Posner Cueing Task (Парадигма Познера)**: Измерение и тренировка скрытого (covert) внимания. Оценка скорости реакции на цель с правильными и ложными подсказками.
- [x] **Оценка усталости (Fatigue Biomarker)**: Анализ микро-вариаций времени реакции (Reaction Time Variability, RTV). Сильное колебание RTV является надежным маркером умственного утомления. Приложение может советовать перерыв.

## 2. Геймификация и Удержание (Retention)
Когнитивные тренировки работают только при регулярности. Fokus нуждается в системах мотивации.
- [x] **Система лиг и Эло-рейтинг (Elo Rating)**: Переход от простых уровней (1-20) к системе скрытого рейтинга, как в шахматах. Подбор сложности должен зависеть от текущего Эло пользователя.
- [x] **Дерево навыков (Skill Tree)**: Визуализация прокачки мозга. Вместо сухих графиков — светящиеся нейронные связи, которые становятся ярче при регулярных тренировках.
- [x] **Ежедневные квесты (Daily Quests)**: Вызовы типа «Заверши 3 блока без единой ошибки» или «Установи новый рекорд в таблицах Шульте».

## 3. Технические улучшения (PWA & Web API)
- [x] **Web Push Notifications**: Локальные уведомления через Service Worker, напоминающие о тренировке в то время, когда пользователь обычно показывает лучшие результаты.
- [x] **Web Share API**: Генерация красивых карточек-картинок с результатами дня для шаринга в Telegram/соцсети в один клик.
- [x] **Web Speech API / Speech Recognition**: Добавление упражнений на вербальную беглость, где нужно произносить слова вслух (например, назвать 10 животных за 30 секунд).
- [x] **Оптимизация бандла**: Разделение кода (Code Splitting) для каждого движка упражнений, чтобы первоначальная загрузка приложения оставалась мгновенной даже при 50+ тренажерах.

## 4. Расширенная аналитика (Insights)
- [x] **Корреляции с образом жизни**: Ненавязчивые вопросы перед сессией («Сколько часов вы спали?», «Уровень стресса 1-5?»). Построение графиков зависимости когнитивных способностей от сна.
- [x] **Хронотип**: Определение оптимального времени суток для сложных интеллектуальных задач на основе исторических данных сессий.
- [x] **Экспорт данных**: Возможность скачать свою статистику в CSV/JSON для самостоятельного анализа.
