# Retention load advisor (G23)

Прогноз нагрузки на **завтра**: полоса rest-light / normal / stretch и 1–2 области. Без новых упражнений, без обещаний IQ, без сравнения с другими людьми.

**Не мержить без ревью.**

## Зачем

G8 говорит, что делать *сегодня* (gate rest-light укорачивает ритуал). G4/G15 смотрят ритм и риск пропуска. G16 выбирает фокус двух недель по EWMA. G20 подбирает текст дня по ситуации.

Не хватало одного шага: после сегодняшней сессии честно сказать, **какой должна быть следующая**. Не «ещё одну», не «прокачай мозг» — полоса нагрузки и одна-две области.

## Архитектура

```
sessions + daySummaries + domains     (storage, schema unchanged)
        │
        ▼
src/core/retention-advisor.ts        pure  →  band + focuses + copy
        │
        ├─ estimateRecovery (G8)     EWMA нагрузки, не второй сглаживатель
        ├─ assessRetention  (G4/G15) усталость, neglect, gap; duck-type skip/churn/floor
        ├─ fortnightFocus   (G16)    опционально, как есть — EWMA двух недель не пересчитывается
        └─ situation id     (G20)    тег fatigue_rest / fatigue_pre / day_done / focus_day / post_miss_comeback
                                     без форка каталога шаблонов
        │
        ├─► getDailySpark            когда день закрыт и совет готов
        └─► Today                    карточка «Коуч · завтра»
```

Ядро не импортирует UI, `registry.ts`, `catalog` и движки упражнений. Карта exercise→domain приходит с экрана из манифестов.

Схему `storage` не поднимали: совет считается, не пишется. Локально, без сети.

```
G8 сегодня          G23 завтра
rest-light    →     rest-light   (если ещё не отдохнули)
steady        →     normal
push-hard     →     stretch
```

Дуэль-матчмейкинг G15 (`matchQuality`, `rankOpponents`) и EWMA фортнайта G16 (`WEEK_ALPHA`, `ewmaDelta`) **не переписываются**.

## Полоса

Карточка **молчит** (`ready === false`), если нет калибровки или меньше **2** scored-сессий. Нет заглушки «тренируйтесь ещё».

Решение — не вторая EWMA. Берём снимок G8 и накладываем правила следующего дня:

| Правило | Полоса |
| --- | --- |
| Пауза ≥ 5 дней | rest-light |
| G15 P(skip) ≥ 0.55 или P(churn) ≥ 0.50 | rest-light |
| Сегодня 2+ сессии или громкая усталость G4 | rest-light |
| Две слабые сессии подряд / просадка качества / 5+ плотных дней | rest-light |
| Сегодня уже прошли rest-light чисто (качество ≥ 62, один заход) | **normal** — не складываем два разгрузочных дня |
| G15 floor.multiplier < 1, пауза ≥ 2, skip ≥ 0.40, серия ≥ 4 дней | stretch запрещён |
| G8 push-hard и нет запрета | stretch |

UI **не показывает** проценты оттока. На экране — «короче / обычный / можно сложнее».

## Области

Ровно **1–2** фокуса, прозрачный `why`:

1. G16 `fortnightFocus` — если передан, берём как есть.
2. G4 `neglectedDomain`.
3. Самая тихая готовая область (низкое значение индекса).
4. `primaryGoal`, если не `balance`.
5. rest-light: если единственный кандидат — вчерашняя область, меняем на другую (как gate G8).
6. stretch: можно продолжить вчерашнюю область, раз запас есть.

Это расклад нагрузки, не IQ и не «прокачка».

## Копирайт

Свои короткие фразы на три полосы. Каталог G20 **не копируется**. Каждая выдача помечается `situation`, чтобы ритуал-копи позже мог подставить свой шаблон, не плодя второй словарь.

Голос: регулярность важнее интенсивности, навёрстывать дни не нужно, усталость просит остановиться. Запрещено: IQ, возраст мозга, нейрофитнес, «прокачай мозг», last chance, you're on fire, штраф.

## UX

- **Сегодня** — карточка под ежедневным коучем, когда совет готов. `role="region"`, заголовок `h3`, области списком. Нет анимации; `prefers-reduced-motion` / `data-motion="reduce"` гасят transition.
- **Коуч** — `getDailySpark` после закрытого дня читает тот же совет (полоса + фокус), иначе остаётся «План выполнен».
- Калибровка и пустая история: секции нет.

Настройки / wipe G14 не трогались. Новых ключей i18n нет.

## Чего нет

- Новых упражнений, правок `registry.ts` и catalog-batch.
- Переписывания `duelIntel.ts` и `coach-longitudinal.ts`.
- Перцентилей, «нормы», сравнения с другими людьми.
- Lockout rest-day: это совет, не запрет сессии.
- Пуш-уведомлений и FOMO-копирайта.

## Не-копи

Wikium / Peak / Elevate / Lumosity / NeuroNation смотрелись как *класс* продукта (нагрузка на завтра, одна мысль, честный порог данных), не как референс копирайта или механик.

| Продукт | Чего нет |
| --- | --- |
| Peak | Streak freeze, «don't break your streak», You're on fire |
| Wikium | «Прокачай мозг», нейрофитнес, возраст мозга, скрипты коуча |
| Lumosity | Brain age, percentile IQ, far-transfer на интеллект |
| Elevate | Stay sharp, productivity-upgrade |
| NeuroNation | Клинический тон, «научно доказанный курс» |

Своё: полоса завтрашнего ритуала из локальной EWMA G8, фокус из G4/G16, ситуации G20 как теги, а не второй каталог.
