# Batch J Exercises

This batch introduces three new unique exercises focusing on memory, attention, and cognitive flexibility:

1. **halo-trace** ("След ореола")
   - **Domain:** Memory
   - **Skills:** Spatial Memory, Sequential Memory
   - **Mechanic:** A grid of pads where random elements light up with a "halo" effect in a sequence. The user must replicate the pattern in the exact order. Length of the sequence and speed of flashes vary by level.

2. **gate-tap** ("Тап у ворот")
   - **Domain:** Attention
   - **Skills:** Sustained Attention, Response Inhibition
   - **Mechanic:** A target sits behind "gates" that occasionally open for a brief window. The user is required to tap the target *only* when the gates are open. Misses and false taps (tapping when gates are closed) are penalized. The open-window duration and cycle interval scale with the level.

3. **dual-label** ("Двойная метка")
   - **Domain:** Flexibility
   - **Skills:** Task Switching, Inhibition
   - **Mechanic:** Users are shown a shape with a word written on it. A cue at the top dynamically changes between "ФОРМА" (Shape) and "СЛОВО" (Word), indicating which attribute of the object the user should select from the multiple-choice buttons. Requires constant attention to the cue to overcome Stroop-like distraction effects.
