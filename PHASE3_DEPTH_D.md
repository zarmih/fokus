# Phase 3 Depth D: Metrics & Retention

## 1. Fokus Index history
* Теперь мы показываем историю Fokus Index на графике-спарклайне за 14 дней вместо 7.
* Добавлена дельта Fokus Index по сравнению с прошлой неделей (7 дней назад).
* Реализован «честный» empty-state: если Fokus Index невозможно рассчитать из-за нехватки данных, экран Progress показывает корректное сообщение с просьбой пройти калибровку и продолжить тренировки.

## 2. Weekly domain goal
* Система еженедельно выбирает самую «слабую» когнитивную область (домен) на основе текущего значения очков области.
* На экране Progress выводится блок, мотивирующий на выполнение тренировок (цель — 10 упражнений для этого домена в неделю).
* Прогресс по цели недели обновляется после завершения каждого упражнения из выбранной области.

## 3. Comeback (Мягкое возвращение)
* При пропуске тренировок более 2 дней на главном экране (Today) появляется отдельная карточка приветствия («С возвращением»), а не стандартная.
* История и накопленные данные не сбрасываются.
* Коуч Fokus добавляет специальный soft insight о том, что перерывы полезны для укрепления нейронных связей. 

## 4. Milestones
* На экране Progress (Статистика) добавлены визуальные отметки серий («Вехи серии» / Milestones) на 7, 14 и 30 дней.
* По мере достижения отметки, иконка меняется и визуально выделяется (с «⏳» на «🔥»).
