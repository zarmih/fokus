# Habit Streak & Ritual Continuity (G11)

Честная модель ежедневного ритуала Fokus: серия считает календарные дни без «заморозки», а после короткой паузы предлагается более короткий знакомый блок. Это удержание привычки, не оценка способностей.

## Зачем

Серьёзные brain-trainer’ы держат возврат в продукт через ежедневный цикл. Fokus делает тот же *класс* задачи — ритуал, мягкий возврат, скромный недельный индекс — своими правилами и своим голосом. Ниже явно, чего мы **не** копируем.

## Чего нет (non-copy)

Не заимствуем копирайт, визуал, бейджи, механики и формулировки:

| Продукт | Что не берём |
| --- | --- |
| **Wikium** | «Нейрофитнес», прокачка IQ, абонементные streak-угрозы, их онбординг и карточки навыков. |
| **Elevate** | «You’re on a roll», Pro-заморозка, их кольца прогресса и тон «ты молодец / не ломай серию». |
| **Lumosity** | BPI / Perfect Day, «brain performance», игровые ачивки-пламя как давление. |
| **Peak** | Genius / lightning-бейджи, платная страховка серии, их календарь-heatmap как UI. |
| **NeuroNation** | Brain age, NeuroScore, «ваш мозг на N лет моложе», paywall продолжения серии. |

Fokus не говорит «не потеряйте серию», не продаёт freeze, не считает IQ и не обещает чудо-перенос в жизнь.

## Архитектура

Слой `core` ничего не знает о DOM. UI только читает снимок.

```
daySummaries / sessions / history  ─┐
exerciseStates (familiar ids)      ─┤
                                    ▼
                         src/core/streak.ts
                         • nextStreak()      — G8, запись DaySummary (не трогаем)
                         • calendarDayKey()  — гражданский день
                         • computeDayStreak()— честный подряд
                                    ▼
                         src/core/continuity.ts
                         • weeklyContinuityScore()  0–1
                         • gentleReturnRitual()     1–2 дня паузы
                         • applyGentleReturnBias()  тонкий хук на уже собранный план
                                    ▼
                         loadContinuitySnapshot(storage)
                                    ▼
              Today / Stats / Settings   + header badge
              (один чип серии + одна подсказка непрерывности)
```

Горячие точки **не** менялись:

- `src/exercises/registry.ts` и модули упражнений — не трогались.
- G9 `insights.ts` / transfer — не импортируется из continuity.
- G10 adaptive / session-builder — не переписывались. Today вызывает `buildTrainingPlan`, затем **рядом** `applyGentleReturnBias`.
- G8 `nextStreak` в `session.ts` по-прежнему пишет `DaySummary.streak` с прощением одного пропуска. Экран больше **не** показывает это число как «дни подряд».

Схема storage не бампалась: всё выводится из уже лежащих сессий, саммари и history.

## Календарный день

Предпочтительная зона: `Europe/Moscow`. Если runtime IANA её не знает — `UTC`, и UI это говорит (`timeZoneSource: utc-fallback`).

Полночь UTC ≠ полночь Москвы (UTC+3, без DST). Инстант `2026-09-05T21:30:00Z` — это `2026-09-06` в Москве. Строки вида `YYYY-MM-DD` считаются уже гражданским днём и не сдвигаются.

День «сыгран», если есть хотя бы одно из: `daySummaries[].date`, `sessions[].startedAt/finishedAt`, `history[].date`.

## Честная серия

`computeDayStreak(playedDays, today)`:

| Состояние | current | Смысл |
| --- | --- | --- |
| `empty` | 0 | Нет истории — тихий no-op. |
| `active` | N | Сегодня уже есть сессия, N дней подряд. |
| `open` | N | Вчера сыграно, сегодня ещё нет. Серия жива, пока день не кончился. |
| `soft_return` | **0** | Пауза 1–2 полных дня. Число не притворяется, что серии не было разрыва. |
| `returned` | 1 | Сегодня первый день после такой паузы. Новый отсчёт. |
| `fresh_start` | 0 | Пауза ≥ 3 дней. |

G8 `nextStreak` по-прежнему может записать 4 после пропуска — это запись саммари, не UX G11.

## Мягкий возврат

Если сегодня не сыграно и полных пропусков 1 или 2:

1. Длительность сессии режется до 5 минут (`SOFT_RETURN_DURATION_SEC = 300`), если в профиле стояло 8/12.
2. План, который уже собрал `buildTrainingPlan`, переупорядочивается к недавним `exerciseId` и доменам из `domainDeltas`.
3. Пустые familiar-списки → перестановки нет (no-op). История пуста / adaptive PR не влит — то же самое: `ritual.active` может быть true, план не ломается.

Копирайт: «Пауза 1–2 дня — обычная история», без вины и без freeze.

## Недельная непрерывность (0–1)

Окно: 7 гражданских дней, оканчиваясь сегодня.

- В расчёт входят только дни **с первой сессии** (новичка не штрафуем за прошлую неделю).
- Сегодня без сессии — *pending*, не дыра (день ещё идёт).
- `score = clamp(0, 1, completed / eligible − Σ penalty(gap))`
  - дыра 1 дня: −0.06
  - дыра 2 дней: −0.14
  - дыра ≥ 3: min(0.36, 0.08 × длина)
- `sufficient` только при ≥ 4 eligible днях. Иначе UI не выдаёт число за «оценку».

Скромный смысл: регулярность ритуала. **Не** IQ, **не** возраст мозга, **не** прогноз навыка.

## UX

Один чип серии + одна подсказка непрерывности на Сегодня / Статистика / Настройки. Шапка показывает честный `current` с `aria-label`.

- Чип не интерактивен; подсказка `role="status"`.
- Нет пульсации и новых анимаций; `prefers-reduced-motion` уже глобально режет transition, для метра — явно `transition: none`.
- Цвета паузы — спокойный accent-2, не danger.

Новых упражнений нет.
