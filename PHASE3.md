# Phase 3: Metrics & Retention (Batch C)

## Что сделано

1. **Fokus Index тренды (Progress)**
   - Добавлен расчет дельты Fokus Index к предыдущему дню.
   - Реализован 7-дневный тренд-график (sparkline) на экране Progress для визуализации динамики индекса.
   - Для каждого домена теперь отображается мини-тренд (↑, ↓, →) с соответствующей цветовой индикацией.
   - Честный empty-state для Fokus Index, если калибровка не пройдена или данных недостаточно.

2. **Недельный отчёт (Weekly Review)**
   - Углублён экран итогов недели. Добавлено отображение общего времени тренировок в минутах.
   - Появился блок «🏆 Лучший день» и «🎯 Зона фокуса» (самый слабый домен).
   - Расширен блок инсайтов до 2-х персональных наблюдений.
   - Добавлен CTA (Call To Action) «Начать дневной ритуал», позволяющий сразу перейти к тренировке (с учетом статуса калибровки).

3. **Streak Shield (Ретеншн)**
   - В `types.ts` добавлена модель `shieldCharges` для профиля.
   - Правило щита реализовано в `streak.ts` и `session.ts`: при пропуске 1 дня тратится 1 заряд щита, сохраняя серию (`skipped: true`).
   - Начисление щитов происходит за каждые 7 дней непрерывной серии (начисляется 1 заряд).
   - На главном экране (Today) отображается мягкий статус: «🛡️ щит спас серию» или «🛡️ щит доступен: N», без лишнего визуального шума.

## Технические детали
- Обновлены unit-тесты (в частности, `streak.test.ts`) для покрытия новой логики сохранения серии с помощью щитов.
- Production-сборка `npm run build` проходит успешно без ошибок.
