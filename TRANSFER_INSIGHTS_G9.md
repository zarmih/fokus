# Transfer Insights G9

Честный перенос из тренировочных доменов Fokus в повседневные навыки и компактная поверхность инсайтов. Без новых упражнений, без правок `registry.ts`.

## Зачем

Удержание в когнитивных тренажёрах часто держится на обещании «прокачать мозг». Fokus идёт другим путём: короткие ритуалы, конкретные задачи на экране и скромный, ситуативный перенос в быт. Этот слой отвечает на вопрос «зачем мне это завтра на кассе / в письме / у двери» — без чуда, IQ и медицинской рамки.

## Архитектура

```
src/core/transfer.ts              чистая карта домен → бытовая ситуация
src/core/transfer-insights.ts     генераторы сессии / недели + фокус недели
src/core/session-builder.ts       тонкий optional-хук focusOfTheWeek
src/ui/components/transfer-card.ts  одна карточка: инсайт + подсказка переноса
Today / Stats / Settings / Итоги недели
```

Существующий `src/core/insights.ts` не трогали: он завязан на `registry` и отдаёт когнитивные наблюдения (тренд навыка, плато). G9 живёт в новых модулях и не импортирует упражнения.

```
сигналы сессии/недели ──► transfer-insights (pure)
домены DomainIndex     ──► suggestFocusOfTheWeek (или null)
                              │
                              ├─► transfer-card  → Today / Stats / Settings
                              └─► focusOfTheWeek? → buildTrainingPlan
                                                    (no-op, если не передан)
```

### Карта переноса (`transfer.ts`)

Пять доменов: Память / Внимание / Логика / Скорость / Гибкость.

Каждая запись:

- `trains` — что упражнение реально тренирует на экране
- `notClaimed` — чего Fokus явно не обещает
- `situations[]` — конкретные бытовые ситуации и скромная связь с практикой

Выбор ситуации детерминирован солью недели (`startOfWeekKey`), чтобы карточка не прыгала при каждом открытии «Сегодня».

### Генераторы (`transfer-insights.ts`)

Берут уже существующие сигналы Fokus, без новых метрик и без схемы хранилища:

| Сигнал | Откуда | Пример наблюдения |
| --- | --- | --- |
| Точность | `SessionItem.accuracy` | низкая точность, спешка, устойчиво высокая |
| Время ответа | `SessionItem.avgRtMs` vs недавнее среднее | медленнее обычного |
| Сложность | `difficultyBefore/After` | сложность выросла, точность удержалась |
| Смесь доменов | `DaySummary.domainDeltas` или опциональная карта exercise→domain с UI | неделя перекошена, сессия узкая |
| Завершение | `finishedAt`, число активных дней | сессия оборвалась, 5/7 дней, неделя пустая |

Мало данных → `warming_up` («Пока рано судить»). Нет чуда из одного блока.

`buildTransferSurface({ prefer: 'session' | 'week' })` собирает **один** инсайт + подсказку переноса + опциональный фокус недели. UI не генерирует текст.

### Фокус недели

`suggestFocusOfTheWeek` возвращает `null`, если:

- меньше двух доменов с ненулевым значением
- меньше двух сессий/дней за 7 дней
- разрыв сильный/слабый < 50 пунктов (профиль ровный)

Иначе выбирает слабый домен, предпочитая тот, который на неделе недогружен (`domainDeltas`). Это **не** программа и **не** адаптивный движок.

`buildTrainingPlan({ focusOfTheWeek })` — необязательный параметр. Не передан → поведение как раньше (no-op для несмерженных adaptive/program PR). Передан → домен попадает в `focusDomains` и получает скромный `weeklyFocusBias` (+18).

Схему `storage` не поднимали: фокус считается, а не хранится.

### UX

Одна карточка `.transfer-card`:

- **Сегодня** — инсайт сессии, если сегодня уже играли, иначе недели; план дня получает `focusOfTheWeek`
- **Статистика** — недельный инсайт + подсказка; «Итоги недели» — то же
- **Настройки** — гид «Что тренируем — и чего не обещаем» со всеми пятью доменами

A11y: `section` + `aria-labelledby`, фокус-кольцо `:focus-within`, без новой анимации. Глобальный `@media (prefers-reduced-motion: reduce)` уже глушит transition/animation.

Не добавляли упражнений, не меняли `registry.ts`, `calibration.ts`, онбординг.

## Голос копирайта

Короткий, деловой русский. Наблюдение → бытовая аналогия → одно действие. Форма плавает, навык не «ломается». Регулярность важнее длины.

Запрещено в положительных обещаниях: IQ, гений, чудо, супермозг, гарантия, лечение, «прокачает мозг».

## Что мы сознательно не копируем

G9 — оригинальная рамка Fokus (ритуал, скромный перенос, честные non-claims). Ниже — что **не** заимствовалось.

### Wikium

Не копировали слоганы про «развитие мозга за N минут», линейку «нейротренажёров», структуру курсов/тарифов, персонажей, визуальный язык кабинета и тексты игровых механик. Наши ситуации бытовые и конкретные, не «нейробика».

### Elevate

Не копировали тон «stay sharp», тренировки письма/речи, фирменные названия игр, прогресс-кольца и рекламные обещания продуктивности. Fokus не продаёт eloquence и не обещает карьерный апгрейд.

### Lumosity

Не копировали Lumosity Score, «unlock your potential», brain-training claims, игровые вселенные и формулировки far-transfer на интеллект. Fokus Index остаётся показателем формы по доменам, не IQ-прокси.

### Peak

Не копировали «workout for your brain», Pro-паки, стиль пиков/лиг как главный крючок и тексты экранов. Серия дней у Fokus — привычка ритуала, не спортзал для мозга.

### NeuroNation

Не копировали апелляции к «научно доказанным» курсам, сертификационный тон и обещания клинического эффекта. Дисклеймер Fokus («не медицинское изделие») остаётся в Настройках.

Если формулировка случайно оказалась близка к чужому маркетингу — её надо заменить, а не «чуть перефразировать». Источник правды: этот файл и `src/core/transfer.ts`.
