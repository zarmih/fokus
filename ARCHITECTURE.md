# Архитектура Fokus

Приложение разделено на чёткие слои для упрощения поддержки и добавления новых тренажёров.

## Слои
- **core** (\`src/core/\`): Работа с профилем, историей, хранилищем (\`storage.ts\`) и глобальными утилитами (аудио, типы). Ничего не знает о UI.
- **ui** (\`src/ui/\`): Экраны (сессия, прогресс, настройки) и компоненты-обёртки. Не содержит логики конкретных игр.
- **session** (\`src/ui/screens/session.ts\`): Оркестратор тренировки. Запускает упражнения из реестра, собирает метрики (\`avgRtMs\`, \`accuracy\`), начисляет очки и обновляет \`history\`.
- **exercises** (\`src/exercises/\`): Папки с конкретными тренажёрами. Каждая папка скрыта за абстракцией \`ExerciseModule\` (см. \`contract.ts\`).

## Правило "Engine без DOM"
Логика каждого упражнения строго разделяется:
- \`engine.ts\`: Управление состоянием (State Machine), генерация уровней, правила победы/поражения. **Не содержит импортов DOM**. Может быть легко покрыт модульными тестами.
- \`view.ts\`: Отображение состояния, обработка кликов/тапов/rAF, и передача действий в \`engine\`. Возвращает функцию \`cleanup()\` для предотвращения утечек памяти при выходе из сессии.
