# План Фазы 0: Оболочка продукта (Fokus)

## 1. Текущее состояние (на базе 0.4.x)
**Уже реализовано:**
- **Product Loop**: Ежедневные сессии (5-12 мин), Fokus Index (0-999), радар профиля, трекинг серии (streak), сборщик сессий.
- **Экраны**: Сегодня (Today), Онбординг (Onboarding), Тренировка (Session), Результаты (Result), Прогресс (Progress), Настройки (Settings), Тренажеры (Trainers), Weekly Review, Дуэли (Duel).
- **Движок**: 18 упражнений (разделение на engine и view), Web Audio, PWA (Service Worker) для работы офлайн.
- **Геймификация**: Квесты, XP, базовая усталость/стресс перед сессией.

## 2. Карта экранов (Phase 0)
Основа навигации (без копирования UI Wikium, свой "премиум" дизайн):
1. **Сегодня (Dashboard)**: Фокус дня, статус прохождения, быстрый старт, виджет состояния (Fokus Index).
2. **Каталог тренажёров**: Сетка упражнений по 5 категориям (Память, Внимание, Логика, Скорость, Гибкость) с фильтрами, карточками и предпросмотром.
3. **Сессия (Workout)**: Бесшовный флоу упражнений, пауза, экран "между" играми (coach-сообщения).
4. **Статистика (Analytics)**: Графики развития по 5 осям, история тренировок, сравнение метрик с "идеальным" профилем (без обещаний IQ).
5. **Достижения & Прогресс**: Уровни, бейджи за специфичные заслуги (например, 7 дней подряд), ветки квестов.
6. **Настройки**: Звук, уведомления (через PWA), сброс прогресса, смена цели.

## 3. Минимальный Design System (Токены)
Дизайн Fokus должен быть сфокусированным, чистым (glassmorphism/dark mode) и динамичным, в отличие от устаревших flat-интерфейсов.
- **Colors**: 
  - *Background*: Глубокие темные оттенки (например, `#0F172A` - slate-900) с акцентами.
  - *Primary/Accent*: Яркие, неоновые или пастельные градиенты (например, Indigo/Violet) для кнопок и Fokus Index.
  - *Surface*: Полупрозрачные панели (`rgba(255, 255, 255, 0.05)` с blur) для карточек.
- **Typography**: Современные шрифты без засечек. Заголовки — *Outfit* или *Clash Display*, наборный текст — *Inter*.
- **Spacing**: 4px/8px/16px/24px/32px (модульная сетка). Скругления: 12px-16px для мягкости.

## 4. Разрывы с уровнем Wikium (Gaps)
- **Программа**: Adaptive Engine v2 закрывает ежедневный ритуал и мягкую перекалибровку (см. `ADAPTIVE.md`, `PHASE2.md`). Долгосрочные марафоны — следующий слой.
- **Каталог**: Нужен удобный поиск и тегирование навыков для каждой игры.
- **Статистика**: Не хватает микро-аналитики (например, скорость реакции в зависимости от времени суток) и перцентилей (где пользователь среди других).
- **Вовлечение**: Глубокая система лиг или глобальный лидерборд.

## 5. Предложенные шаги (PR-sized chunks)
1. **PR 1: Внедрение базового Design System**: Настройка CSS-переменных (цвета, шрифты, отступы), обновление `styles.css` и применение базовых токенов к общим компонентам (кнопки, карточки).
2. **PR 2: Редизайн экрана "Сегодня" и Навигации**: Внедрение новой структуры меню (Bottom Bar / Sidebar), обновление дашборда для лучшей визуализации Fokus Index.
3. **PR 3: Полноценный Каталог тренажёров**: Обновление экрана `trainers.ts`, добавление фильтров по 5 категориям, красивых карточек для всех 18 игр.
4. **PR 4: Улучшение экрана Статистики**: Добавление новых графиков (радар, линейный график по дням) на экран `progress.ts`.
5. **PR 5: Полировка Сессии и Результатов**: Улучшение транзишенов между играми, финального экрана результатов с шарингом и анимацией получения XP.
