# Batch D (Exercises)

Добавлены 3 новых уникальных упражнения:

1. **rhythm-tap** (Ритм)
   *Домен:* speed
   *Механика:* Повторение ритмического рисунка пульсации тапами по экрану.

2. **mirror-pick** (Зеркальное отражение)
   *Домен:* flexibility
   *Механика:* Выбор правильного зеркального отражения фигуры среди отвлекающих вариантов (включая повороты).

3. **order-recall** (Порядок)
   *Домен:* memory
   *Механика:* Запоминание последовательности символов и восстановление их исходного порядка после исчезновения.
