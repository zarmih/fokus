# PWA Release Checklist

Чек-лист готовности к выпуску Progressive Web App (PWA) приложения **Fokus**.

## 1. Web App Manifest (`public/manifest.webmanifest`)
- [x] Присутствуют обязательные поля: `name`, `short_name`, `description`, `start_url`, `scope`, `display`, `icons`.
- [x] Относительные пути (`start_url: "./"`, `scope: "./"`) для корректной работы как в корне домена, так и на подпутях (например, GitHub Pages `/fokus/`).
- [x] Режим отображения: `standalone` и `display_override: ["standalone", "minimal-ui"]`.
- [x] Иконки: PNG-иконки 192×192 и 512×512 для установки и отдельная maskable-иконка 512×512.
- [x] Тематические цвета (`theme_color`, `background_color`) соответствуют темной теме `#0F1020`.

## 2. Service Worker и Precache (`scripts/generate-sw.ts`, `vite.config.ts`)
- [x] Автоматическая генерация `sw.js` при сборке (`vite build`).
- [x] Precache включает:
  - Корневой `index.html` и основной бандл приложения.
  - Упражнения 14-дневной базовой программы (`CORE_EXERCISE_IDS`).
  - Все калибровочные пробы (`CALIBRATION_PROBE_IDS`).
  - Общие модули упражнений (`assets/ex-lib-*.js`) и иконки доменов.
- [x] Остальные упражнения каталога кэшируются на лету при онлайн-прохождении (runtime cache).
- [x] Поддержка навигационного fallback на кэшированный `index.html` в офлайн-режиме.
- [x] При переходе со старого service worker сохраняется совместимость с кнопкой, которая только перезагружает страницу. Следующие версии ждут подтверждения. После `SKIP_WAITING` активируется, берёт страницу под управление и перезагружает её.

## 3. Обновления и Жизненный Цикл PWA
- [x] Отслеживание нового SW через событие `updatefound` и переход в состояние `installed`.
- [x] Отправка глобального события `pwa-update-available`.
- [x] Баннер обновления (`pwa-update-banner.ts`):
  - Не блокирует текущий процесс пользователя (non-modal alertdialog).
  - Фокусируется корректно, доступен для скринридеров (a11y).
  - Глобальный слушатель в `main.ts` работает и на онбординге, и при переходах между экранами.
- [x] Обновление по нажатию кнопки применяет новую версию без потери данных (подтверждено E2E: сохраняются сессии, калибровка, серия в `e2e/pwa-release-scenarios.spec.ts`).

## 4. Офлайн-режим и Сохранность Данных
- [x] Первый запуск сохраняет профиль в `localStorage`.
- [x] Офлайн-индикатор предупреждает об отсутствии сети.
- [x] Прохождение тренировок офлайн сохраняет результаты локально.
- [x] Экспорт и импорт профиля в настройках: анонимный экспорт вырезает PII (имя, сон, стресс), полный экспорт сохраняет PII; сверено с текстом политики приватности (`e2e/pwa-release-scenarios.spec.ts`, `e2e/offline-and-data.spec.ts`).
- [x] Удаление локального профиля и кэшей с подтверждением ключевым словом `УДАЛИТЬ` (`e2e/pwa-release-scenarios.spec.ts`).
- [x] Офлайн-восстановление сессии: прерванная сессия возобновляется с сохраненным остатком бюджета без повторного запроса чекина (`e2e/pwa-release-scenarios.spec.ts`).
- [x] Автоматический локальный бекап перед очисткой.

## 5. Доступность (a11y) и Адаптивность
- [x] Корректные `aria-live` регионы для таймеров и подсказок.
- [x] Поддержка `prefers-reduced-motion` для снижения интенсивности анимаций на canvas и DOM.
- [x] Альтернативные метки (цветонезависимые символы/надписи/направление стрелок) в упражнениях на распознавание цветов (`odd-one`, `stroop`, `helix-flip`).
- [x] Клавиатурное управление основными упражнениями, prefers-reduced-motion и проверки интерактивных элементов (`e2e/pwa-release-scenarios.spec.ts`).

## 6. GitHub Pages Deployment
- [x] Базовый путь `/fokus/` настроен в `vite.config.ts` для production-сборок.
- [x] Workflow `.github/workflows/deploy.yml` настроен на развертывание ветки `main` в GitHub Pages.

### Действия, оставшиеся владельцу (не автоматизируются ботом):
1. **Проверка на физических устройствах**:
   - iPhone / Safari: «Поделиться» → «На экран «Домой»» (проверка иконки, сплеш-скрина и standalone-режима).
   - Android / Chrome: проверка системного баннера установки или меню «Установить приложение».
2. **Публикация релиза**:
   - Создание релизного тега Git (например, `v0.7.0` или `v1.0.0`) в репозитории GitHub.
   - Проверка успешного деплоя в GitHub Pages: `https://zarmih.github.io/fokus/`.
3. **Согласование бюджетов производительности**:
   - Определение пороговых значений FPS/памяти на слабых мобильных устройствах.
