# Основной каталог Fokus (ядро программы на 14 дней)

Ядро — 15 упражнений, по 3 на каждую из пяти областей. Именно из них «Тренировка на сегодня» собирает
ежедневную сессию первые 14 дней. Остальные 166 упражнений остаются в «Каталоге» и в истории: ничего не
удаляется, прошлые результаты по ним сохраняются и учитываются в аналитике как раньше.

## Критерии отбора

1. Узнаваемая парадигма с понятной инструкцией: одна механика, одно правило.
2. Из каждого кластера дублей (см. `inventory.md`) берётся один представитель.
3. Есть `manifest/engine/view` или хотя бы отдельный генератор, таблица уровней и тесты.
4. Нет зависаний и падений, есть cleanup, без ввода не набирается «хорошая» точность.
5. Две упражнения-вехи программы (`tide-gate`, `anchor-pair`) входят в ядро, потому что планировщик закрепляет их
   на дни-вехи (`program-phases.MILESTONE_EXERCISE_IDS`).
6. Внутри области упражнения разнообразят навыки (`skills`), а не повторяют одно и то же.

Покрытие областей: по 3 упражнения на каждую из пяти. В сессии на 5/8/12 минут (3/4/5 блоков) планировщик
выбирает разные области: за 14 дней каждая область встречается не реже одного раза на 2–3 тренировки.

## Что не вошло и почему (примеры)

- `n-back` (Dual N-Back): нужен синтез речи, беззвучного режима нет; без ввода 52 %; таблица уровней не
  используется. Остаётся в каталоге. Включить в ядро после визуального режима, помеченного как другие условия
  измерения (шаг 4).
- `verbal-fluency`: зависит от распознавания речи, без него засчитывает 100 %.
- `corsi`, `posner`: `levels: {}`, блок не ограничен; их кластеры представлены `sequence` и `go-no-go`.
- `schulte`: отдаёт `rounds = 0`; кластер «числа по порядку» не нужен в ядре при наличии `math-sprint`.
- 15 WCST-вариантов: в ядре один (`helix-flip`).
- `avatar-names`, `word-pairs`, `shape-count`, `dot-span`: зависали (исправлено в `feat/core-generator-hangs`),
  но в ядро не берутся.

## Как ядро используется в коде

- `src/core/core-catalog.ts`: список `CORE_EXERCISE_IDS`, `isCoreExercise(id)`, `coreCatalog(registry)`.
- Единый планировщик (`src/core/daily-plan.ts`) первые 14 дней программы берёт кандидатов только из ядра.
  Если упражнения ядра исключены (уставший домен, «Не сегодня»), он добирает из полного каталога той же области.
- Каталог («Тренажёры») показывает все 181 упражнение, ядро помечено.
