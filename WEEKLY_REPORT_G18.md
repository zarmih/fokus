# Weekly cognitive report G18

Недельный нарратив из **локальной** истории Fokus: какие области реально работали, честная серия, хук переноса G9 и карточка, которая остаётся на устройстве. Без новых упражнений, без правок `registry.ts`.

**Не мержить без ревью.**

## Зачем

Экран «Итоги недели» уже умел считать дни/сессии и показывать G3-коуча. Не хватало связного текста: что тренировали, не притворяется ли серия семью днями подряд, и куда это ложится в быт. G18 собирает один отчёт из уже существующих сигналов — без новых метрик и без сети.

## Архитектура

```
sessions + daySummaries + domains     (storage, schema unchanged)
        │
        ▼
src/core/weekly-report.ts            pure  →  narrative + mix + streak honesty + share payload
        │
        ├─► buildTransferSurface({ prefer: 'week' })   хук G9, не второй генератор
        │
        ▼
Итоги недели
  glance → narrative → domains → streak calendar → G3 intel → what changed → transfer-card → local share card
```

Ядро не импортирует UI, `registry.ts` и движки упражнений. Карта exercise→domain приходит опционально с экрана из `catalog` (только манифесты).

Схему `storage` не поднимали: отчёт считается, а не пишется.

```
сигналы недели ──► weekly-report (pure)
                      │
                      ├─► domains trained / neglected
                      ├─► streak honesty (played ≠ forgiven skip)
                      ├─► narrative (headline + 2 абзаца)
                      ├─► transfer surface (G9)
                      └─► share payload  →  canvas PNG download (local only)
```

## Окно

Семь **календарных** UTC-дней, включая `asOf`. Сессия 8 дней назад в отчёт не попадает. Пустой день — отсутствие сессии, а не ноль на графике.

## Области

Пять доменов: Внимание / Память / Скорость / Гибкость / Логика.

Домен «в работе», если за неделю был блок (через `domainByExercise`) или ненулевой `domainDeltas`. Иначе — «тихо». Смесь:

| mix | Когда |
| --- | --- |
| empty | ничего не тренировали |
| warming | мало сессий или рано судить |
| narrow | почти всё в одной области |
| skewed | одна область ≥ 1.6× следующей |
| balanced | три и больше без явного перекоса |

Это расклад нагрузки, не IQ и не «прокачка».

## Честная серия

Продуктовая серия Fokus умеет прощать **один** пропуск (`nextStreak`, `skipped: true` на дне возврата). G18 не называет это «днями подряд».

Календарь недели:

- **played** — день с сессией (или саммари с очками, не skipped-only)
- **forgiven** — пустой день перед возвратом с `skipped: true`
- **missed** — пауза без прощения

| kind | Смысл | Можно ли писать «подряд» / “in a row” |
| --- | --- | --- |
| empty | сессий не было | нет |
| intact | живой ряд из ≥2 дней без дыры | да, только для этого ряда |
| forgiven | в живом ряде есть прощённый пропуск | нет |
| broken | на неделе играли, но ряд сброшен | нет |
| sparse | есть сессия, календарь не сплошной | нет |

Прощённый день — пауза, не тренировка. Пустая клетка не становится «почти серией».

## Нарратив

Один заголовок и два коротких абзаца. UI не генерирует текст.

Голос: empty → forgiven → broken → warming (≤2 дней) → habit (≥5 подряд без дыры) → sparse.

Второй абзац может подмешать смесь областей и **хук** G9 (`focus` или `insight.title`) — не дублируя карточку переноса целиком.

Мало данных → «Пока рано складывать неделю». Нет чуда из одного блока.

## Карточка (local only)

`shareWeeklyCard` рисует PNG на canvas и скачивает `fokus-week.png` через `<a download>`. Если canvas недоступен — тот же текст файлом `fokus-week.txt`.

Сознательно **нет**:

- `navigator.share` / Web Share API
- `fetch` / upload / облако
- серверного шаринга

Подпись на карточке: локальная история, не IQ, не диагноз.

## UX

- **Статистика → Итоги** — тот же вход
- **Итоги недели** — нарратив, сетка областей, календарь серии, затем G3, «Что изменилось», карточка переноса G9, «Следующий шаг», превью + «Скачать карточку»
- Пустая неделя: честный empty, без кнопки шаринга и без «Что изменилось»

A11y: `region` + `aria-labelledby` / `aria-label`, фокус-кольцо `:focus-within`, без новой анимации. Глобальный `prefers-reduced-motion` уже глушит transition/animation.

Не добавляли упражнений, не меняли `registry.ts`, калибровку, онбординг.

## RU+EN

Строки отчёта живут в `src/core/i18n.ts` (`weekly.*`, `domain.*`). Ядро принимает `locale` и не зависит от DOM. Русский по умолчанию — существующие тесты G3/G9 не ломаются. Панель G3 на этом экране по-прежнему на русском: это чужой слой, G18 его не переводит.

## Голос копирайта

Короткий, деловой. Факт → оговорка → одно действие. Серия без прикрас. Регулярность важнее длины.

Запрещено в положительных обещаниях: IQ, гений, чудо, супермозг, гарантия, лечение, «прокачает мозг». Отрицание («не IQ») допустимо.

## Что мы сознательно не копируем

G18 — оригинальная рамка Fokus (ритуал, честная серия, скромный перенос). Ниже — что **не** заимствовалось.

| Продукт | Чего не брали |
| --- | --- |
| **Wikium** | «нейроотчёт», мозговой возраст, энергия, тарифные сводки |
| **Elevate** | stay sharp, кольца прогресса, карьерный апгрейд |
| **Lumosity** | Lumosity Score, unlock your potential, far-transfer на интеллект |
| **Peak** | workout for your brain, лиги как главный крючок недели |
| **Duolingo** | серия, которая прячет пропуск за streak freeze без слов |

Если формулировка случайно близка к чужому маркетингу — заменить, а не «чуть перефразировать». Источник правды: этот файл и `src/core/weekly-report.ts`.
