# Отчёт: Fokus до уровня топ-5 когнитивных приложений

Дата: 2026-09-08  
Версия: 0.4.0

## Что считается «топ-5»

По обзорам 2025–2026 лучшие потребительские приложения в категории — **BrainHQ**, **Lumosity**, **Peak**, **Elevate**, **CogniFit**. Их общий продуктный контур:

1. Короткий ежедневный ритуал, а не каталог игр.
2. Адаптивная сложность.
3. Один узнаваемый индекс (LPI / Peak Brain Score / clinical battery).
4. Радар или профиль по доменам.
5. Коуч, который говорит, *зачем* сегодняшняя сессия.
6. Праздник результата и повод вернуться завтра.
7. Честность: тренируем задачи, перенос в жизнь скромный.

Fokus уже имел сильную внутреннюю механику (19 упражнений, адаптация, калибровка, квесты, XP). Не хватало именно этого контура.

## Что сделано

| Рычаг топ-приложений | Как сделано в Fokus |
| --- | --- |
| Ежедневный workout | Экран «Сегодня» начинается с сессии дня, а не с простыни графиков |
| Индекс | **Fokus Index** 0–999 по пяти областям, без фейковых процентилей |
| Визуальный профиль | Радар внимания / памяти / скорости / гибкости / логики |
| Онбординг | Цель, длительность, имя, научный дисклеймер, сразу калибровка |
| Коуч | Ежедневная реплика: старт, привычка, восстановление, хронотип, фокус |
| Результат | Счёт, сравнение с прошлой сессией, форма, шаринг-карточка |
| Привычка | Серия, квесты с XP, новые достижения, локальные напоминания |
| Трение | Сон/стресс можно пропустить; усталость спрашивает, а не обрывает |
| Честность | Нет обещаний «прокачать IQ». Корреляции сна помечены как корреляции |

## Что сознательно не делалось

- Новые мини-игры. Их уже 19, а разрыв с топ-5 был в продукте, не в каталоге.
- Фейковое сравнение с «людьми вашего возраста» — без нормативной выборки это обман.
- Серверные push и лиги с живыми соперниками — для PWA без бэкенда это отдельный этап.
- Клинические батареи уровня CogniFit/BrainHQ — Fokus остаётся потребительским тренажёром.

## Как проверялось

- TypeScript (`tsc --noEmit`) без ошибок.
- 99 тестов Vitest: индекс, коуч, онбординг, «Сегодня», результат, адаптивность, сборщик сессий.
- Браузерный прогон Playwright (Chrome, 390×844 и 1280×800):
  - онбординг → калибровка «Лишний»;
  - «Сегодня» с Fokus Index 429, радаром, сессией дня и коучем;
  - старт сессии без блокирующего вопроса про сон;
  - аналитика, настройки (напоминание + пропуск сна), тренажёры с русскими доменами.

Не прогонялась полная 5-минутная сессия до шаринг-карточки (нужно живое прохождение блоков).

## Что даст следующий скачок

1. Нормативная выборка и честный процентиль (как LPI), когда появятся анонимные агрегаты.
2. Настоящие Web Push через сервер.
3. Недельный «Daily Spark» в духе BrainHQ — одно упражнение на скорость обработки.
4. Более живые упражнения (тайминг, haptics), не новые жанры.
