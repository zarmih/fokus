# Changelog
## Diff curves G19
- Intra-block warmup → plateau → surge around the Adaptive Engine / staircase anchor
- Shared helpers in `src/core/diff-curves.ts`; stroop, switch-rule, posner, grid-memory, n-back opt in
- Calibration band shrinks amplitude; n-back keeps `n`; block observations still use the assigned level
## [0.5.1] - Session quality & recovery
- Качество ритуала (0–100) из точности, стабильности реакции, сложности, завершённости и обрывов — не «балл мозга»
- Короткий горизонт нагрузки (EWMA) и подсказка rest-light / steady / push-hard на экране «Сегодня»
- После плотных дней Today может собрать более короткий ритуал в другой области; выключается в Настройках
## Offline sync G6
- Версионированный экспорт (`fokus-backup`, схема 4, checksum) и импорт merge/replace
- Миграции 1→4, снимок до импорта, восстановление из `.bak` при битой записи
- История больше не обрезается на 30; настройки показывают схему/ревизию и превью файла
## [0.5.0] - Adaptive Engine v2
- Вектор способностей по 5 областям: EWMA-форма/база и байесовская уверенность
- IRT-выбор сложности (зона вызова ~P 0.65–0.80) и spaced-слоты overdue / due / fresh
- Мягкая перекалибровка по давности или дрифту, без сброса серии
- Экран «План» и проводка в Сегодня / Сессию / Результат, с откатом на старый сборщик
## [0.4.2] - Motion G2
- Токены длительности и easing, утилиты `.fx-enter` / `.fx-ok` / `.fx-bad` / `.fx-celebrate`
- Жизненный цикл сессии: вход в блок, микрофидбек, праздник результата
- Физика нажатия карточек каталога и анимация ритуала на «Сегодня»
- Единые аудио-кью `playCue` поверх существующего Web Audio слоя
- Предпочтительный путь `prefers-reduced-motion` (fade вместо тряски и петель)
## [0.4.1] - Feel + offline
- Удары, промахи и комбо через Web Audio, с учётом настройки звука
- Service Worker кэширует собранные ассеты, офлайн-оболочка и корректный base `/fokus/`
## [0.4.0] - Product loop
- Fokus Index (0–999) и радар когнитивного профиля
- Онбординг с целью, длительностью и научным дисклеймером
- Экран «Сегодня» как ежедневный ритуал: коуч, сессия дня, серия
- Экран результата: форма, сравнение, шаринг-карточка
- Квесты дают XP, новые достижения, локальные напоминания
- Сон/стресс можно пропустить; усталость спрашивает, а не обрывает сессию
- Калибровка заканчивается экраном профиля, а не пустым «Сегодня»
