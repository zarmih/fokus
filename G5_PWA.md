# G5: PWA, Установка и Офлайн

## Установка приложения (PWA Install UX)
- В настройках теперь есть улучшенный блок установки, который отображается, если приложение может быть установлено (через `beforeinstallprompt`).
- Добавлена более интуитивная обработка кнопки.
- Окно установки информирует пользователя, что это позволяет получить быстрый доступ без браузера.

## Офлайн и Кэширование (Offline/Cache Trust)
- Приложение больше не выдаёт пугающих красных ошибок ("Ошибка навигации") при попытке открыть новый экран без интернета, если скрипт ещё не закеширован.
- Вместо этого выводится спокойное серое уведомление «Офлайн режим» и сообщается, что данные в безопасности на устройстве.
- При загрузке приложения (`init`), если нужные компоненты не могут загрузиться из-за отсутствия сети, пользователь также видит понятный статус офлайна.
- Добавлен глобальный слушатель событий `offline` / `online` (через `offline-banner.ts`). При пропадании интернета снизу появляется аккуратный системный баннер «Офлайн режим. Данные сохраняются локально.», помогающий понять, что тренировка не будет утеряна.
