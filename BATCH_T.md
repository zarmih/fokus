# Batch T Exercises

В этом батче добавлены 3 новых упражнения, архитектура которых строго разделена на логику (\`engine.ts\`), представление (\`view.ts\`), манифест (\`manifest.ts\`) и точку экспорта (\`index.ts\`).

## Упражнения:
1. **Pulse Rail (Пульс-рельс)** — *Attention / Inhibition*
   Тренировка селективного внимания и торможения. В центре отображается целевой цвет. Пользователь должен реагировать (влево или вправо) только на объекты целевого цвета и игнорировать остальные.
2. **Vault Span (Хранилище)** — *Memory / Working Memory*
   Классическая задача на емкость рабочей памяти. Пользователь запоминает последовательность появления монет в ячейках 3x3 и воспроизводит ее.
3. **Frame Swap (Смена кадра)** — *Flexibility / Task Switching*
   Тренировка когнитивной гибкости. Пользователь переключает правила в зависимости от формы рамки: при круглой рамке необходимо совпадение по цвету, при квадратной — по форме.
