# Batch N Exercises

This batch introduces three new cognitive exercises for the Fokus platform:

1. **Вспышка (`flare-pick`)**
   - **Domain**: Attention (Selective attention, Inhibition)
   - **Mechanic**: User watches a field of dim dots. Periodically, one dot briefly flashes bright. The user must tap ONLY the dot that just flashed, and ONLY during its brief flash window. False taps are penalized. The duration of the flash and the interval between flashes shrink as the level increases.

2. **Гнёзда (`nest-span`)**
   - **Domain**: Memory (Working memory, Spatial memory)
   - **Mechanic**: A brief flash of various items (like fruits or shapes) is shown, distributed across 2-3 "nests" (containers). The nests then empty out. The user must restore the items from a pool to their correct nest. Order inside the nest does not matter, only membership. The number of items (span) increases with level.

3. **Сдвиг жетона (`token-warp`)**
   - **Domain**: Flexibility (Rule switching, Cognitive flexibility)
   - **Mechanic**: A stream of tokens with multiple features (Color and Shape) is presented. The active classification rule (e.g., "Sort by: COLOR" or "Sort by: SHAPE") is displayed and periodically changes (warps). The user must sort the current token into the correct category based on the *active* rule. Errors following a rule warp are heavily penalized.
