# Ritual copy intelligence G20

Умный копирайт дня и ритуала: усталость, серия, тон после пропуска. Каталог шаблонов, а не одна захардкоженная фраза. Без новых упражнений, без правок `registry.ts`.

## Зачем

Ежедневный коуч раньше выбирал текст цепочкой `if`. Одни и те же три предложения всплывали каждый день; усталость, серия и пропуск жили в разных модулях и часто не доходили до экрана «Сегодня».

G20 собирает сигналы, выбирает **ситуацию**, затем **вариант шаблона**. В один день текст стабилен (не мигает при повторном рендере). Между днями варианты ротируются, чтобы ритуал не звучал как спам.

Голос тот же, что у дневного коуча: регулярность важнее интенсивности, один пропуск уже прощается, навёрстывать дни не нужно, усталость просит остановиться.

## Архитектура

```
сигналы (серия, пропуск, усталость, recovery, фокус)
        │
        ▼
src/core/ritual-copy.ts     pure: ситуация → шаблон → слоты
        │
        ├─ getDailyRitualCopy / getDailySpark   ← src/core/coach.ts
        └─ Today (баннер коуча + кикер карточки) ← src/ui/screens/today.ts
```

`ritual-copy.ts` не знает о DOM, `storage` и упражнениях. UI не генерирует предложения.

Существующие модели не дублируются:

| Сигнал | Откуда |
| --- | --- |
| Усталость после сессии | `assessRetention` → `session_fatigue` |
| Нагрузка до сессии | `estimateRecovery` → `rest-light` / `loadEwma` |
| Серия, прощённый пропуск | `streak` + `skippedYesterday` + `gapDays` |
| Тихий домен | retention `domain_neglect` ≥ 70 |
| Окно дня | `analyzeChronotype` |
| Фокус | план дня / цель / слабый домен |

Схему `storage` не поднимали. `lastTemplateId` есть во входе как опция антиповтора; экран его не пишет.

## Ситуации (приоритет)

Первое совпадение побеждает. Played-today и пропуск важнее серии и фокуса.

| id | Когда | Тон |
| --- | --- | --- |
| `uncalibrated` | нет калибровки | start |
| `fatigue_rest` | сегодня уже играли и усталость громкая | habit |
| `day_done` | план дня закрыт | habit |
| `post_miss_forgiven` | один пропуск, серия ещё жива (в т.ч. «завтра после вчерашнего пропуска») | recovery |
| `post_miss_comeback` | пауза ≥ 3 дней или серия 0 при истории | recovery |
| `fatigue_pre` | `rest-light` или высокая нагрузка, ещё не играли | recovery |
| `streak_milestone` | ровно 7 / 14 / 30 | habit |
| `streak_fragile` | серия ≥ 7, час ≥ 16, не сыграно | habit |
| `streak_building` | серия 2–6 | habit |
| `domain_wait` | neglected domain, сигнал ≥ 70 | focus |
| `chrono_window` | сейчас сильное окно | time |
| `focus_day` | есть домен плана | focus |
| `streak_hold` | длинная серия днём, без другого крючка | habit |
| `science_default` | иначе | science |

У каждой ситуации **не меньше трёх** шаблонов. Слоты: `{streak}`, `{streakDays}`, `{domain}`, `{minutes}`, `{chrono}`, `{gapDays}`. Шаблон с незаполненным слотом в пул не попадает.

Ротация: `hash(localDay + situation) % n`. Если передан `lastTemplateId` и в пуле есть другой вариант — берём следующий.

## UX

- **Коуч** — `getDailySpark` остаётся прежним контрактом `{ title, body, tone }`. Внутри — `composeRitualCopy`.
- **Сегодня** — баннер читает ту же модель (`data-copy-situation`, `data-copy-template`). Карточка «план выполнен» берёт `cardTitle` / `cardBody`. Кикер незакрытого ритуала: при recovery-gate по-прежнему «Сегодня легче», иначе `cardKicker` (после пропуска — «Серия на месте» / «Короткий возврат»).
- Калибровочная карточка не подменяется шаблоном: дисклеймер «не IQ» остаётся как был.

Двухдневный простой до сессии больше не обнуляет цифру серии на «Сегодня»: прощение из `nextStreak` (`diffDays === 2`) уже доступно, и тон после пропуска может опереться на живую серию.

## Голос

Короткий деловой русский. Наблюдение → одно действие. Форма плавает, навык не «ломается».

Запрещено в каталоге: IQ-обещания, «прокачай мозг», нейрофитнес, возраст мозга, «не пропусти», last chance, you're on fire, «отработай», штраф.

После пропуска: не долг и не навёрстывание. Усталость: остановиться, не «ещё одну». Серия: привычка ритуала, не спортзал для мозга.

## Что мы сознательно не копируем

G20 — оригинальный голос Fokus. Ниже то, что **не** заимствовалось.

| Продукт | Чего нет |
| --- | --- |
| Peak | Streak freeze, «don't break your streak!!!», You're on fire |
| Wikium | «Прокачай мозг», нейрофитнес, скрипты коуча |
| Lumosity | Unlock your potential, far-transfer на интеллект |
| Elevate | Stay sharp, productivity-upgrade |
| NeuroNation | Научно доказанный курс, клинический тон |

Если формулировка случайно близка к чужому маркетингу — её надо заменить в каталоге, а не «чуть перефразировать». Источник правды: этот файл и `src/core/ritual-copy.ts`.

## Ограничения

- Реестр упражнений и движки сессии не расширялись.
- Недельный коуч (`coach-intel`) и nudges retention на «Статистике» не переписывались: G20 — день и ритуал.
- Нет пуш-уведомлений и FOMO-копирайта.
- Текст не хранится: считается при открытии «Сегодня».
