# Batch Q Exercises

## Overview
Added three new unique cognitive exercises focusing on Attention, Memory, and Flexibility domains. 

1. **wave-lock (Волна)** - *Attention* (Sustained Attention, Reaction Speed, Inhibition)
   - Inspired by Focus and precision timing mechanics found in apps like Peak and Elevate.
   - The user must wait for the moving wave to enter a designated target zone and hit SPACE to lock it in place. Accuracy depends on precise timing.

2. **grid-stash (Сетка-тайник)** - *Memory* (Visual Memory, Spatial Memory)
   - Inspired by spatial memory recall tasks like Lumosity's Memory Matrix.
   - The user is presented with a grid. Several cells light up briefly and then hide. The user must click to reveal the exact locations of the previously lit cells. 

3. **rule-pivot (Поворот правила)** - *Flexibility* (Task Switching, Rule Switching, Cognitive Flexibility)
   - Inspired by rule-switching paradigms such as the Wisconsin Card Sorting Test, frequently adapted in NeuroNation.
   - The user must sort a central card (e.g. a red square) into one of two bins based on a continuously changing rule: either "По цвету" (By color) or "По форме" (By shape). This forces the brain to switch contexts rapidly.
