# Batch P Exercises

This batch introduces three new cognitive exercises:

## 1. beacon-snap (Маяк)
**Domain:** Attention
**Mechanics:** A ring/grid of beacons is displayed. A brief cue sets a target color. Beacons flash rapidly one by one in different colors. The user must snap-tap the target beacon when it flashes, while ignoring false flashes (distractors). The answer window shrinks and the distractor probability increases with level.

## 2. slot-span (Ячейки)
**Domain:** Memory
**Mechanics:** A sequence of glyphs is briefly flashed across multiple slots. Then the slots are emptied, and a palette of glyphs appears below (including distractors). The user must reconstruct the exact sequence by selecting glyphs in order. The span length and distractors increase with level.

## 3. prism-flip (Призма)
**Domain:** Flexibility
**Mechanics:** A stream of tokens (varying in both color and shape) is evaluated against a sorting rule ("ЦВЕТ" or "ФОРМА"). The user must select the option that matches the central token based on the active rule. The rule can abruptly "flip" between color and shape. Errors made on the old rule right after a flip are penalized. The flip frequency increases with level.
