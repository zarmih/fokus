# BATCH V

## Новые упражнения
1. **Маяк-рельс (beacon-rail)**
   - **Домен**: Внимание (Attention)
   - **Навыки**: Selective attention, Inhibition
   - **Механика**: Игрок должен следить за двигающимся элементом на "рельсе" и нажимать кнопку (или Пробел), когда в центральную зону попадает элемент нужного цвета (целевой маяк). Отлично тренирует торможение реакций (inhibition) и избирательное внимание, аналогично CPT-тестам.
   - **Вдохновение**: Peak / Lumosity (Continuous Performance Tasks).

2. **Кэш (cache-span)**
   - **Домен**: Память (Memory)
   - **Навыки**: Working memory, Spatial memory
   - **Механика**: В нескольких ячейках на короткое время появляются различные символы, после чего они скрываются. Игроку необходимо вспомнить и указать, в какой ячейке находился заданный символ.
   - **Вдохновение**: Аналоги пространственной рабочей памяти из Lumosity (Pinball Recall, Memory Matrix).

3. **Смена мотива (motif-flip)**
   - **Домен**: Гибкость (Flexibility)
   - **Навыки**: Rule switching, Task switching
   - **Механика**: Игроку предъявляется карточка, и он должен выбрать подходящую пару из двух вариантов по текущему правилу (по Цвету или по Форме). Правило периодически случайным образом меняется, заставляя мозг переключать контекст.
   - **Вдохновение**: Task Switching тесты (Peak, NeuroNation).
